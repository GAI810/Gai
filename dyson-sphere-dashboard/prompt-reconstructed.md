请用单个 HTML 文件做一个「戴森球运作监控系统」前端页面，可直接在浏览器打开。

## 视觉与场景
- 全屏深空黑底，赛博朋克科幻风；主色青蓝霓虹（#0ff），辅以橙黄恒星光。
- 用 Three.js 构建 3D 场景：中心有一颗会轻微脉动的恒星；外层是半透明线框戴森球壳（如二十面体细分）；再加 3 条不同轴向、颜色各异的粒子环（蜂群），缓慢自转。
- 背景散布大量星点；给场景加雾效和 Bloom 辉光。
- 支持 OrbitControls：鼠标拖拽旋转、滚轮缩放，并开启自动环绕旋转。

## 界面 HUD（中英双语）
- 顶部标题：`DYSON SPHERE`，状态「OPERATIONAL / 运作中」带闪烁指示灯。
- 左侧系统指标面板：恒星光度、能量捕获率、当前输出、结构完整性、框架旋转（可含模拟数值，如光度 3.828×10²⁶ W、捕获率 98.4%、完整性 100%）。
- 右侧或另一侧日志面板：滚动输出短日志（如连接主节点、等离子流稳定、蜂群同步）。
- 底部能量存储进度条，百分比动态变化。
- 开场有「系统初始化中 / INITIALIZING SYSTEM…」加载遮罩，短暂后淡出。
- UI 层不阻挡 3D 交互（pointer-events 穿透到画布）。

## 技术要求
- 单文件 HTML，内联 CSS/JS；Three.js 及 OrbitControls、EffectComposer / UnrealBloomPass 等可用 CDN。
- 当前输出、能量条、日志用定时器模拟实时刷新。
- 窗口缩放时自适应画布。
- 不要后端、不要构建工具。
